# DBSM Page

Create a dynamic, peaceful replica of https://dbsm.dbtech.in/ with:

* Full-screen background videos, photos, and Bing-style wallpapers.
* Smooth animations, transitions, and parallax effects.
* Clean, modern, responsive design for all devices.
* Professional Inter/Roboto typography with fluid sizing.
* Optimized WebP/AVIF images, lazy loading, compression, CDN caching, and fast performance.
* Accessible motion controls with `prefers-reduced-motion`.
* Preserve the original DBSM content and structure while giving it a more modern, immersive feel.
